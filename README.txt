# Página para ella ❤️

1. Abre `index.html` en el navegador para verla.
2. En `js/script.js`, cambia `startDate` por la fecha real de ustedes.
3. En `index.html`, reemplaza los textos de ejemplo por su historia real.
4. No incluye sección de fotos, como pediste.

La página funciona únicamente con HTML, CSS y JavaScript; no necesita Node para verla.
